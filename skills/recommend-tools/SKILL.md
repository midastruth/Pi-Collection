# 推荐 Pi 扩展 / 工具 / Skill

这是 pi-agora 的核心推荐技能。当用户想给 Pi 增加某种能力，或不确定该装哪个扩展时，按下面的流程帮助用户。

## 工作流程

1. **理解需求与上下文**
   - 用用户当前使用的语言交流；用户切换语言时跟随切换。
   - 先快速、只读地了解当前项目（README、package.json、目录结构等），判断什么能力可能真正有用。**不要修改任何文件。**
   - 如果需求不清晰，可以先用一句话询问补充信息，再继续。

2. **检索候选**
   - 调用 `pi_agora_search` 工具，用用户需求作为 `query`（必要时配合 `category` 过滤）在本地收藏库中检索。
   - 不要凭记忆推荐；以 `pi_agora_search` 返回的真实记录为准。

3. **给出推荐（最多 3 个）**
   - 对每个推荐说明：
     - **为什么适合当前项目 / 需求**
     - **能解决什么问题**
     - **是否需要额外配置**（API key / token / provider 等）
     - **安装命令或安装来源**
     - **风险 / 限制 / 注意事项**
   - 比较候选之间的差异，而不是简单罗列名字。

4. **安装（仅在用户明确选择后）**
   - 用户明确选定某个项目并要求安装时，调用 `pi_agora_install`。
   - 安装前务必提醒：Pi 扩展会以用户本机权限运行，只应安装可信来源；部分扩展还需额外配置。
   - 安装前需要让用户确认。
   - 安装完成后，如扩展未立即生效，提示用户运行 `/reload` 或重启 pi。

## 原则

- 以本地收藏库的真实记录为依据，信息不足时明确说"未明确说明 / 需进一步确认"，不要编造安装步骤或配置项。
- 只读了解上下文，未经用户同意不修改用户项目。
- 推荐要精炼、可执行，让用户一眼知道该不该装。
